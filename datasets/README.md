# Datasets

この教材はローカルで確実に動かすため、scikit-learn付属データセットと、教材に同梱した架空のCSV・文章・日付順の記録を使います。

## 利用する主なデータセット

| データセット | 使う章 | 内容 |

| `make_classification` | 15 | 不良品が約5%の人工データ1,000件 |

第6章は、コード内で作った16件の架空の顧客データを使います。
第0章は3件の架空の家賃を学習用、別の2件を確認用に使います。
過学習のグラフは、仕組みを見やすくするため `make_moons` で作る2種類の人工データを使います。
第14章も `make_moons` を使いますが、件数と分割は学習曲線用の条件です。
第15章の4列は人工的な測定値で、実際の寸法や重さの単位はありません。0を正常、1を不良品と見立てています。
種類の割合は`weights=[0.95, 0.05]`で指定し、`flip_y=0.01`で一部のラベルをランダムに付け直すので、出来上がりの割合は厳密に95対5ではありません。

## 「1行」「1列」「答え」の意味

Iris を例にすると、1行は1つの花、4つの列は花の測定値、答えはその花の品種です。

```python
from sklearn.datasets import load_iris

data = load_iris(as_frame=True)
print(data.data.head(3))  # 最初の3つの花の測定値
print(data.target.head(3))  # 同じ3つの花の品種番号
print(data.target_names)  # 品種番号に対応する名前
```

`data.data` と `data.target` の同じ行番号が1組になります。
糖尿病データの特徴量は加工済みの尺度なので、BMI や血圧の普段の単位としては読みません。
診断データでは元の番号が「0＝悪性、1＝良性」です。
第4・5・7・10章では悪性を陽性として評価するため「1＝悪性、0＝良性」に付け直しています。

データの詳しい定義は[糖尿病データの公式説明](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_diabetes.html)を参照してください。

## 第13章の架空の家賃CSV

[rent_practice.csv](rent_practice.csv)は、[生成コード](../scripts/make_rent_data.py)で作った120件です。
実在の物件情報を使っていません。家賃の単位は月あたりの万円です。

| 列 | 単位・値 | 空欄 | 役割 |
| --- | --- | --- | --- |
| `room_id` | R001〜R120 | なし | 結果を確認する番号 |
| `area_sqm` | 18〜70㎡ | 7件 | 手がかり |
| `walk_min` | 1〜25分 | 8件 | 手がかり |
| `age_years` | 0〜40年 | 6件 | 手がかり |
| `zone` | central（中心部）/ suburb（郊外） | 5件 | 手がかり |
| `rent_man` | 万円 | なし | 当てたい答え |

空欄は列ごとに作るので、同じ部屋の複数の列が空欄の場合もあります。
生成コードは、広さ・時間・築年数・地域を使った説明用の式に、偶然のずれを加えます。
その後、手がかりの一部を空欄にします。現実の相場を表す式ではありません。
乱数の出発点を42に固定しているので、同じ環境で再生成すれば同じ例になります。

CSVは同梱済みなので、普段は再生成する必要はありません。
作り方を試す場合は `.venv/bin/python scripts/make_rent_data.py` で同じCSVを上書きします。
Windowsは `.venv\Scripts\python.exe scripts/make_rent_data.py` です。

## 追加した題材の条件

第20章の電力量は、気温20℃から離れるほど増える架空の式に偶然のずれを加えます。
実際の電力を推定する物理モデルではありません。学習240件、最終テスト80件です。

第21章は、一人ごとの練習時間・確認問題の点・固有のずれを4記録で共有します。
まだ記録のない人を予想する条件なので、48人192行で選び、別の12人48行で最後に確かめます。
点数は架空の連続値で、必ず0〜100に収まる設定ではありません。`student_id`は分割用で、入力から外します。

第23章は数字1件を64列で扱い、1,437件を学習用、360件を最終テストにします。
学習用の中にも早期停止用の部分があります。詳しい役割は[第23章](../exercises/ch23_neural_network.md)を確認します。

第24章は、正常を中心付近、異常を離れた位置に作った見分けやすい2列の人工データです。
単位は実際のセンサー値ではなく、説明用の尺度です。学習は正常期間の入力240件だけです。
検証・最終テストはそれぞれ通常80件と異常20件。正解は0＝通常、1＝異常で、モデルの1/−1とは別です。
現実の未知の異常を同じ成績で拾えるとは言えません。

第25章はクラスの割合を指定せず、学習600件・選択200件・最終テスト200件に分けます。
6列は単位を持たない人工的な値で、うち4列は他の列と関係する冗長な列です。
第15章の不良品5%のデータとは別の条件です。

第26章は家賃CSVを学習60件・幅の調整30件・最終テスト30件に分けます。
幅の調整用は、モデルの重みを学ぶために使いません。

第27章は空欄のない部屋データを新しく生成します。家賃の式は説明用で、現実の相場ではありません。
学習300件のモデルを固定し、基準120件と広さの分布を変えた120件を比べます。
「関係も変化」は後者と同じ入力を使い、答えへ2.5万円を足した仮想比較です。
この二つを独立した実際の期間として扱わないようにします。
正解の到着が遅れる例では、同じ120件に対して未到着・40件到着・全件到着を比べます。

## 自分の CSV を使う場合

`pandas.read_csv()` で読み込み、説明変数 `X` と目的変数 `y` に分けると、この教材の多くのコードを再利用できます。
読み込みから評価まで動かせる例は[第13章](../exercises/ch13_csv_regression.md)にあります。

```python
import pandas as pd

df = pd.read_csv("datasets/my_data.csv")
X = df.drop(columns=["target"])
y = df["target"]
```

上の例は形を示す抜粋です。自分のCSVでは、答えの単位、数値と文字の列、空欄を確認します。
番号や予測時点ではわからない列を手がかりに入れないようにしてください。
同じ人・同じ部屋の繰り返し記録や、日付順の予測には、それに合う分割も必要です。
第13章のランダムな分割は、この架空の部屋一覧の練習用です。
日付順の予測は[第19章](../exercises/ch19_time_series.md)で、過去から後の日を確かめる方法を学びます。

## 第18章の架空の問い合わせ

[コードの `make_messages()`](../scripts/ch18_text_classification.py)に48件の文を置いています。
`text` が文章、`label` が `shipping`（配送）か `payment`（支払い）です。すべて教材用に書いた架空の例です。
二つの話題を含む予測用の文には、この例の正解ラベルを用意していません。
実際の問い合わせに多い表現や、種類の割合を代表するデータではありません。

## 第19章の架空の販売個数

[コードの `make_sales()`](../scripts/ch19_time_series.py)で、毎日1行の210日分を作ります。
販売個数は整数、単位は個です。乱数の出発点を42に固定し、曜日の波・日ごとの増加・偶然のずれを加えます。
日付は2025年1月1日〜7月29日です。先週の値がない最初の7日を除き、173日を学習用、最後の30日を最終テストにします。
毎日実績を受け取って翌日を予想する条件です。複数店舗や欠けた日、数週間先の一括予測は、この例では扱いません。
