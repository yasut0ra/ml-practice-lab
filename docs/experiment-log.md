# 実験ノート

[学習の道順](learning-path.md) · [教材の入口](../README.md)

このページの空欄の表を、自分のメモにコピーして使います。
1回の実験で変える条件は1つにし、実行前の予想も残してください。
数値が良くならなくても、理由や追加で確かめたいことが書ければ学びになります。

## 記録すること

| 項目 | 自分のメモ |
| --- | --- |
| 章・実行したファイル | |
| 入力X・当てたい答えy | |
| 予想する時点と、その時点でわかる手がかり | |
| 確かめたい疑問 | |
| 変更する1か所 | |
| 実行前の予想と理由 | |
| 比べる指標と、良い方向 | |
| 同じにした条件（データ・分割・乱数） | |
| 変更前の結果 | |
| 変更後の結果 | |
| 結果から言えること | |
| この結果だけでは言えないこと | |
| 次に確かめたいこと | |

## 記入例：第8章でkを変える

| 項目 | 記入例 |
| --- | --- |
| 疑問 | 一番近い1件だけで答えると、5件の多数決より良い？ |
| 変更 | k-NNの `n_neighbors=5` を `1` にする |
| 予想 | 特殊な例に引っ張られて、確認用の正解率は下がるかもしれない |
| 指標 | accuracy。高いほど良い |
| 同じ条件 | データ・分割・標準化・`random_state` を固定 |
| 結果 | 実行して出た2つの数値を、ここに書く |
| 解釈 | この分割でどちらが良かったかは言える。別のデータでいつも同じとは言えない |

結果の数値は、手元で実行して記入します。予想と違っても、メモを書き直す必要はありません。

## 比較を読むときの確認

- [ ] 同じ確認用の問題で、同じ指標を比べた。
- [ ] 平均を答える・最多の種類を答える、といった単純な基準と比べた。
- [ ] 1回の成績と、CVの平均・ばらつきを区別した。
- [ ] 設定を選ぶために見たデータと、最後のテストを区別した。
- [ ] 精度の数値から、原因や現実での成功を断定しなかった。
- [ ] 文章の辞書・重みなど、データから決める前処理を学習用だけで作った。
- [ ] 時間順の予測では、何日先を当て、いつ実績を受け取るかを決めた。
