# 総合課題：選んだモデルの結果を説明する

[学習の道順](learning-path.md) · [第10章](../exercises/ch10_model_comparison.md)

第0〜10章の仕上げです。目安は60〜90分。
付属の診断データを使い、「入力の準備 → 基準との比較 → モデル選び → 最後の評価 → 説明」を通して行います。

## 提出するもの

動くPythonファイル、CVの比較表、最後のテスト結果、5〜10文の説明を作ります。
独学なら「提出」は自分のメモに残すことです。

## 手順

1. 入力の手がかりと、当てたい答えを1文で説明する。陽性は悪性の1とする。
2. 全体の約25%を最終テストとして取っておく。
3. 学習用の中の5分割CVで、単純な基準と2つ以上のモデルを比べる。前処理はPipelineに入れる。
4. モデルを選ぶ指標を先に決める。この課題ではF1を使い、同率なら名前順で決める。
5. CVの比較結果を保存し、選んだモデルを学習用すべてで学び直す。
6. 最終テストでaccuracy・precision・recall・F1と混同行列を求める。
7. 結果と、この結果だけではわからないことを書く。テストを見て設定を選び直さない。

## 保存する表

CVの比較表は `outputs/model_comparison.csv`、最後のテストは `outputs/final_test_metrics.csv` に保存します。
比較表にはモデル名とaccuracy・F1・recallの平均、最後のテストには選んだ名前・指標・TN/FP/FN/TPを入れます。

## 説明を書くための問い

- 何を入力し、何を当てようとした？
- なぜaccuracyだけでなくF1も見た？
- 単純な基準と比べてどうだった？
- 最終テストを、モデル選びのどこまで使わずに残した？
- どの間違いが何件あった？
- 別のデータでも同じ成績になると言える？追加で何を確かめたい？

## 完了の目安

| 観点 | 自分で確認すること |
| --- | --- |
| 入力と答え | Xの1行・1列、yの0・1を説明できる |
| 公平な比較 | 同じ分割・同じ指標で、基準を含めて比較している |
| 評価の分離 | CVと前処理に最終テストが入っていない |
| 結果の読み方 | 指標と4種類の件数を、日常の言葉で説明できる |
| 再実行 | 同じコマンドで結果の表を作り直せる |
| 結論の範囲 | 今回の結果から言えること・言えないことを分けて書ける |

精度に合格点は設けません。高い数値だけでなく、評価の手順と説明がそろえば完了です。
