# 何を学ぶかを選ぶマップ

[教材の入口](../README.md) · [時間と前提の一覧](learning-path.md) · [用語早見表](../cheatsheet.md)

この教材は全28章です。最初は第0〜3章、次に第4〜6章へ進みます。
以降は「今、何を確かめたいか」で選べます。すべての手法を暗記することが目標ではありません。

## 機械学習の仕事を、一周で見る

| 段階 | 自分に聞くこと | 学ぶ場所 |
| --- | --- | --- |
| 問いを決める | 数値・種類・似た集まり・珍しい例のどれを知りたい？ | 第0〜3・9・24章 |
| 入力を用意する | 予想する時点で使える列？空欄や文字はある？ | 第1・6・13・18〜20章 |
| 評価を設計する | 初めて見る行・人・未来のどれを予想する？ | 第4・5・10・19・21章 |
| 方法を比べる | 単純な基準よりよい？設定をどこで選ぶ？ | 第2・3・7・8・10・11・22・23章 |
| 結果を読む | 件数・見逃し・手がかり・確率・幅を説明できる？ | 第12・14〜16・25・26章 |
| 使って確かめる | 同じ前処理を再利用できる？答えが来てからも測れる？ | 第17・27章、[モデルカード](model-card.md) |

各段階は一方通行ではありません。誤差の原因を考えたら、新しい実験として入力や方法を見直します。
すでに結果を見た最終テストを、次の設定選びと新しい最終評価に兼用しないようにします。

## 似ている言葉を分ける

| 二つの言葉 | 見分け方 | 関連する章 |
| --- | --- | --- |
| 分類／クラスタリング | 正解の種類を渡して学ぶか、入力だけで似たものを集めるか | 3・9 |
| 森／ブースティング | 木を別々に学んでまとめるか、今の誤差を順に補うか | 7・22 |
| しきい値／確率の校正 | 判断の境目を選ぶか、確率と実際の割合の対応を整えるか | 15・25 |
| 重要度／原因 | モデルが使う手がかりの目安か、変化が結果を起こす関係か | 16 |
| 異常候補／故障 | 普段と違う入力か、本当に対処が必要な出来事か | 24 |
| 予測区間／信頼区間 | 新しい一件の答えの幅か、平均・係数など推定する量の幅か | 26 |
| 入力の変化／誤差の悪化 | 手がかりの分布が変わったか、答えとのずれが増えたか | 27 |

## 数学・Pythonに戻りたいとき

Pythonの行の読み方は[最初のガイド](getting-started.md#コードを読むための最低限の約束)、
平均・損失・重み・勾配は[数と学習の読み方](math-intuition.md)で小さな例を使います。
コードと図を先に見て、式は必要になったときに戻っても構いません。

## この教材の範囲と、その先

ここでは、小さなデータをCPUで動かし、評価の手順と結果の説明を練習します。
大規模な深層学習、生成モデル、推薦、強化学習、因果推論、サーバーへの配信基盤は実装していません。
文章分類はTF-IDF、画像分類は小さな全結合ネットワークまでです。

次に進むときも「予測時点の入力」「適切な分割」「単純な基準」「未使用の評価」「結果の限界」を持ち越します。
[総合課題](capstone.md)と[モデルカード](model-card.md)を仕上げると、学んだ範囲と次の疑問が整理できます。
