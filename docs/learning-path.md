# 学習の道順

[教材の入口](../README.md) · [はじめてのガイド](getting-started.md)

1章を完璧にする必要はありません。下の「できたら次へ」が説明できたら先に進み、必要なときに戻ります。
時間は読む・実行する・小さな変更を試すところまでの目安です。練習問題は別の時間に取り組んでも構いません。

「設定を自分で選びたい」なら第11章、「点の位置を見たい」なら第12章、
「手元の表で予想する流れを体験したい」なら第13章を選んでください。
その後、「次にデータを増やすべきか」なら第14章、「少ない対象を見逃していないか」なら第15章、
「モデルがどの列を使っているか」なら第16章へ進めます。

「毎日の記録から翌日を予想したい」なら第19章がおすすめです。章番号順にすべて進める必要はありません。

## 1章の進め方

1. 図を見て、入力と出力を1つずつ言う。
2. 実行する前に「どうなりそうか」を予想する。
3. サンプルを動かし、見たい数字を1つ選ぶ。
4. 「まずはここだけ」を試す。変えるのは1か所にする。
5. [実験ノート](experiment-log.md)に、変更前後と考えた理由を書く。
6. 「この章のゴール」で確認する。

わからなければ、まず各章の「つまずいたとき」を開きます。
解答は[実行コードと読み方](../answers/README.md)を一緒に見て、コピーした部分の役割を説明してみてください。

## 一通り学んだら

[総合課題](capstone.md)で、「何を当てたいか → 何で比べるか → モデル選び → 最後の確認 → 結果の説明」を通して行います。
うまく動いたかだけでなく、「なぜそうしたか」「どこまで言えるか」を自分の言葉で書くのが目標です。
発展編を学んだら、総合課題の[発展編を使った追加課題](capstone.md#発展編を使った追加課題)にも取り組めます。
