# Chapter 1: 機械学習の基本概念

## 短い説明

機械学習の最小単位は、入力 `X`、正解 `y`、学習するモデル、予測値です。
この章では `bmi` という 1 つの特徴量から、糖尿病の進行度を単回帰で予測します。

## 実行

```bash
python scripts/ch01_basic_concepts.py
```
