# Chapter 1: 機械学習の基本概念

## この章でわかること

「データを用意する → 学ぶ → 予想する」をコードと結びつけられるようになります。
最初は `X`・`y`・`fit`・`predict` の4つを見つけられれば十分です。

## 身近な例と図解

過去の「部屋の広さと家賃」から、新しい部屋の家賃を予想すると考えてみましょう。
広さが **X（手がかり）**、家賃が **y（答え）**、関係を見つける仕組みが **モデル**です。

![過去の手がかりXと答えyで学習し、新しい手がかりだけで予測する。予測値は実際の答えと比べる](../docs/images/learning-flow.svg)

この章のコードでは、部屋の代わりに糖尿病データを使います。
`bmi`（体格に関する指標）を手がかりに、1年後の病気の進行度を表す数値を予測します。
このデータの `bmi` は加工済みの値で、普段目にする BMI の数値とは異なります。

## 実行

```bash
.venv/bin/python scripts/ch01_basic_concepts.py
```

Windows のコマンドは[ガイド](../docs/getting-started.md#第1章を動かすまで)を参照してください。

## コードの読み方

| コード | していること |
| --- | --- |
| `load_diabetes(as_frame=True)` | 練習用のデータを、表として読み込む |
| `X = data.data[["bmi"]]` | 手がかりの表から `bmi` の列を選ぶ |
| `y = data.target` | 正解の数値を取り出す |
| `LinearRegression()` | 直線の関係を学ぶモデルを準備する |
| `model.fit(X, y)` | 手がかりと答えから関係を学ぶ |
| `X.iloc[[0]]` | 最初の1件を、表の形のまま取り出す |
| `model.predict(example)` | その手がかりから答えを予想する |

## 結果の見方

- `特徴量の形: (442, 1)` は「442件のデータに、1種類の手がかりがある」という意味です。
- **実測値**は実際の答え、**予測値**はモデルが出した答えです。違いがあっても正常です。
- **係数**は直線の傾きです。正なら、このモデルでは `bmi` が増えると予測値も増えます。

今回は学習に使ったデータの1件を予測しています。初めて見るデータへの実力は、まだ測っていません。
第2章で、学習用と確認用にデータを分けます。

## グラフで見る

[グラフを生成](../README.md#実際のデータをグラフで見る)して `outputs/figures/01_regression.png` を開きます。
横軸は加工済みの BMI、縦軸は進行度です。英語表示ならそれぞれ `BMI (scaled)` と `Progression score` です。
点は確認用データの実際の値、線は学習データから得た予測です。
点が線の上にぴったり並ばないのは、1つの手がかりだけでは説明しきれない違いがあるからです。

## まずはここだけ

`print(X.head(3))` と `print(y.head(3))` を `y = data.target` の下に加えてください。
同じ行番号が「1件分の手がかりと答え」の組になっていることを確認しましょう。

## 練習問題

1. `bmi` だけでなく `bp` も特徴量に追加してください。
2. 最初の 5 件について、実測値と予測値を並べて表示してください。
3. 係数の符号と大きさを比べてください。このデータは特徴量の尺度がそろっていますが、係数だけで原因や重要性を断定しないようにしましょう。

## ヒント

```python
X = data.data[["bmi", "bp"]]
pred = model.predict(X.iloc[:5])
```

<details>
<summary>理解の確認：予測するときにも、答え y を渡す？</summary>

渡しません。`fit` には手がかりと答えを渡し、`predict` には手がかりだけを渡します。
予測したあと、実際の答えと比べて確かめます。

</details>
