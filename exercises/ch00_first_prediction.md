# Chapter 0: 家賃を予想してみよう

初めてコードを動かすための導入です。目安は15〜20分。専門用語を覚える前に、予想が出るところまで試します。

## この章でわかること

過去の例で学ぶことと、新しい入力の答えを予想することの違いを体験します。

## 身近な例と図解

すべて架空の部屋です。広さが20㎡増えると、家賃が4万円増える例を3つ用意します。

| 広さ X（㎡） | 家賃 y（万円） |
| --- | --- |
| 20 | 6 |
| 40 | 10 |
| 60 | 14 |

![広さと家賃から規則を学び、新しい部屋の広さから家賃を予想する](../docs/images/learning-flow.svg)

コードはこの3つから関係を学びます。図の30㎡とは別に、まず**35㎡の家賃**を予想してみます。

## 実行前に予想する

35㎡は20㎡と40㎡の間です。6万円と10万円の間の、どのくらいになりそうですか？
紙や[実験ノート](../docs/experiment-log.md)に、自分の予想を1つ書いてから実行します。

## 実行

[セットアップ](../README.md#セットアップ)を済ませてから、次を実行します。

```bash
.venv/bin/python scripts/ch00_first_prediction.py
```

Windows は `.venv\Scripts\python.exe scripts/ch00_first_prediction.py` を使います。

## コードの読み方

| 行 | していること |
| --- | --- |
| `X_train = [[20], [40], [60]]` | 3行・1列の手がかりの表を作る。`[[...]]` は表の形 |
| `y_train = [6, 10, 14]` | 同じ順番で、3件の実際の家賃を用意する |
| `model.fit(X_train, y_train)` | 広さと家賃の関係を学ぶ |
| `new_area = 35` | 新しく予想する部屋の広さを決める |
| `model.predict([[new_area]])` | その家賃を予想する。入力は1行・1列 |
| `[0]` | 予想の並びから、最初の1件を取り出す |

## 結果の見方

```text
35㎡の部屋の予想: 9.0万円
確認用: 30㎡ / 実際 9.0万円 / 予想 8.0万円
確認用: 50㎡ / 実際 12.0万円 / 予想 12.0万円
ずれの平均（MAE）: 0.50万円
```

35㎡の実際の家賃は与えていないので、その予想の正しさはまだわかりません。
確認用の2部屋なら、答えがあるので比べられます。ずれは1万円と0万円で、平均は0.5万円です。
実際の家賃には場所や築年数も関係します。少数の作った例でうまくいくことと、現実で役立つことは別です。

## まずはここだけ

`new_area = 35` の `35` を `25` に変えてください。
実行前に予想し、変えたあとに7万円と出るか確認します。

## 練習問題

1. 25㎡と45㎡を、それぞれ予想してください。
2. 100㎡も予想してください。学習に使った広さの最小・最大と比べます。
3. 「100㎡でも当たりそう」と言うために、どんなデータが追加で必要かを1文で書いてください。

<details>
<summary>ヒント：2件まとめて予想するには？</summary>

`model.predict([[25], [45]])` のように、1件ずつ行を分けます。
100㎡は学習した20〜60㎡の範囲を超えています。大きな部屋でも同じ関係が続くかを考えてみてください。

</details>
